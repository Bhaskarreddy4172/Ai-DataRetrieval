UNIVERSAL DATASET QA DEMO DATA

MAIN DATASET:
main_dataset/india_states_capitals_main.csv
This is the parent State -> Capital dataset.

CHILD DATASETS:
child_datasets/ contains one CSV for each state-capital pair.
Each child dataset contains synthetic village-level data.

IMPORTANT:
Child demographic values are synthetic demonstration data, NOT official statistics.
They are intended for testing parent-child retrieval, filtering, spelling correction,
aggregation, comparisons, multilingual questions, and follow-up queries.
