# ULTIMATE MASTER PROMPT

## Universal AI Dataset Retrieval, Semantic Understanding, Spell Correction, Entity Resolution & Verified Answer Engine

You are upgrading an existing AI Dataset Retrieval project.

The objective is to transform the current system into a **universal, highly accurate natural-language dataset question-answering platform**.

The system must allow a customer to upload an arbitrary CSV, Excel, JSON, or similar structured dataset and then ask questions in **any natural form**, including professional, informal, broken English, unprofessional wording, slang, abbreviations, spelling mistakes, phonetic spellings, synonyms, indirect questions, incomplete questions, possessive questions, multi-condition questions, analytical questions, comparison questions, relationship questions, and follow-up questions.

# 1. MOST IMPORTANT RULE

## NEVER use this architecture:

```text

        ↓

        ↓
```

```text

        ↓

        ↓

        ↓

        ↓

        ↓

        ↓

        ↓

        ↓

        ↓
QUERY PLANNING
        ↓
QUERY PLAN VALIDATION
        ↓
PANDAS / DUCKDB EXECUTION
        ↓
EXACT VERIFIED RESULT
        ↓
RESULT VALIDATION
        ↓
HALLUCINATION FIREWALL
        ↓
OLLAMA NATURAL-LANGUAGE RESPONSE
```

### Responsibility separation

**OLLAMA:**

* Understand natural language
* Normalize user language
* Detect intent
* Understand synonyms
* Resolve semantic meaning
* Generate structured query plans
* Understand conversation context
* Explain verified results

**PYTHON / PANDAS / DUCKDB:**

* Read the dataset
* Filter rows
* Sort
* Rank
* Count
* Sum
* Average
* Median
* Min/max

* Perform date operations

Never allow Ollama's pretrained knowledge to replace the uploaded dataset.

# 23. QUERY DECOMPOSITION

Complex questions must be split into deterministic steps.

Example:

```text
Who is the highest-paid employee in Hyderabad and what department does he belong to?
```

Plan:

```text
1. Filter City = Hyderabad
2. Find maximum Salary
3. Retrieve employee
4. Retrieve Department
```

Another example:

```text
What is the capital of the state where the highest-paid employee works?
```

Plan:

```text
1. Find highest-paid employee
2. Retrieve employee's city
3. Resolve city → state
4. Resolve state → capital
5. Return capital
```
